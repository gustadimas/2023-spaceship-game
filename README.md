# SpaceShip Game

Feito em mai/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Shooter espacial pequeno: a nave atira laser e pode pegar power-up. Depois reaproveitei o `Player.cs` e o `Laser.cs` daqui no PF.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/SpaceShipGame.unitypackage` em Assets > Import Package > Custom Package.

## Créditos

A pasta `Assets/Plugins/CodeAssist` é um plugin de terceiros.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
